# 开发状态与验收范围

源码 0.5.9，Windows 开发预览。当前公开包的具体测试数量与构建身份以 `validation.json` 和 `SOURCE-MANIFEST.json` 为准，不累计不同阶段的重叠测试。

| 能力 | 已有实现与证据 | 边界 |
| --- | --- | --- |
| 工程与会话 | 新会话选择插件参与；工程管理、右侧引用、顶部调整记录、紧凑结果卡 | 停用或卸载后的“插件缺失”提示待宿主接口 |
| PLC 修改 | 共用 OpenPLC 原生编辑工具，可创建 POU、编辑变量及受支持的 ST/LD；真实梯形图差异查看 | 不是任意 PLC 品牌或所有梯形图结构；需要适配源码与原生工具 |
| HMI 修改 | FUXA 画面文字、名称、只读值及声明接口；多轮候选、审阅与保留 | 复杂画面任意重绘及原生未保存草稿回收未统一 |
| OIP 修改 | 当前工程中创建场景、部件编辑、信号绑定、原生检查；保持候选归属 | 固定原版 2026.11.9 指纹；静态检查不代表外部 PLC 实时联动通过 |
| 三工具同步 | 日常 DSH 已验证联合修改、查看、同工程保留/撤销及结果卡和资源更新 | DSH 重启后的已有 OpenPLC 窗口可能需要重开；历史预览不会冒充当前版本 |
| 运行关系 | 已保存、编译、Runtime 装载/RUN/STOP、FUXA/OIP 通道分别显示 | 新界面验收没有替代最新构建的真实运行与故障恢复验收 |
| 统一运行事件 | 结构化编译回执、候选检查、实例状态、FUXA 通信/数据与工具错误；事件有版本、实例和恢复历史 | 完整进程 stdout、FUXA 驱动/浏览器日志和 OIP 仿真日志未全面采集 |
| 工具下载 | OpenPLC 适配版、FUXA/OIP 中文补丁、Runtime 与编译依赖统一入口 | 尚无全新 Windows 完整安装验收；独立 OIP 中文版与 DSH 桥接不能直接等同 |

同一工程内“保留”形成保存版本，继续使用原会话；“撤销”只作用于未保留候选。历史版本回滚和原生手工修改回收不属于本轮语义。

模型由 DSH 选择，工程工具和上下文由插件管理。工具调用兼容性取决于宿主与模型，不能推广为所有供应商/模式；结果未知按原记录核对，不自动重试修改或运行动作。

源码构建、离线测试、模型生成、原生编译、软件 Runtime、三维联动和硬件验收分别计证据。源码发布与维护者日常界面核对不证明跨机、实时性、工业安全或课堂可靠性。
