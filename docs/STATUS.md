# 开发状态与验收范围

2026-11-07；源码 0.5.0；Windows 开发预览。

| 能力 | 已实现／已验证 | 边界 |
| --- | --- | --- |
| DSH 插件 | 工程、资源／实例拓扑、对话关联、任务与候选审阅；本包构建／测试另记 validation.json | 历史 UI 与当前源码测试分别记录 |
| 原生团队 | PLC／HMI／OIP 三名真实成员产物及 Lead 组装有同机历史证据 | 此次发布准备不调用模型；故障时序未穷尽 |
| 保留／撤销 | A 保留新 UUID 并编译；B 撤销并保留源工程 | 证据只对原固定版本有效 |
| 三端运行 | 原冻结输送带 A 的 3／5 件、启停和运行中断线恢复有同机软件结果 | 不代表任意 OIP 场景；未打包第三方 OIP 部件 |
| 声明接口 | BOOL／INT／REAL、权限与可编辑原生 FUXA 画面 | 任意复杂类型／设备插件／权限组合未验 |
| 同机环境恢复 | 新目录、配置、UUID、DSH profile，编译、实际运行及重开；历史核对 20 项 | 复用同机已安装工具，跨机及联网全新安装未验 |
| 新风机案例 | TON、新绑定、实际 Runtime 15 项、编译产物 34 项、保存改名移动重开 | 无 OIP 场景，无实体风机 |
| 工程移动 | 停止后同 UUID 迁移；相关回归 28 项 | 现存重复副本或活动 Runtime／工具／端口仍拒绝 |

历史结果来自维护者本机，公开包保留压缩事实及源码指纹，不包含原始服务目录、鉴权 URL、模型账本或聊天。不同阶段测试有重叠，不相加声称总覆盖率。

待办：干净 Windows 全链安装复现；定制编辑器依赖公开复建；风机 OIP；长期后台／跨机／课堂／硬件／实时性；GitHub Actions 实际结果跟踪。

源码检查、协议测试、模型生成、原生编译、实际 Runtime、三维物理场景、硬件和教学是不同验收层级。
