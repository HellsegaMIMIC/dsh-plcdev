历史结果来自维护者本机，公开包保留压缩事实及源码指纹，不包含原始服务目录、鉴权 URL、模型账本或聊天。不同阶段测试有重叠，不相加声称总覆盖率。

本次对话与模型解耦实施的开发环境回归为 Node 207 项、指定 Python 53 项及构建通过；真实桌面 A/B 验证共 4 次供应商请求，后台候选生成没有附加模型请求。发布树自身的检查结果单独记录在 `validation.json`，不将本机工具链测试视为新用户完整安装通过。

待办：跨供应商与 PTC 兼容、团队模型解耦及数值修订；干净 Windows 全链安装复现；定制编辑器依赖公开复建；风机 OIP；长期后台／跨机／课堂／硬件／实时性。

源码检查、协议测试、模型生成、原生编译、实际 Runtime、三维物理场景、硬件和教学是不同验收层级。
