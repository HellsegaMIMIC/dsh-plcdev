发布候选由明确的源码清单导出，不复制工作区 Git 历史。

不包含 `.tools/`、`outputs/`、node_modules、venv、EXE、运行副本、数据库、聊天、浏览器 profile、密钥配置、模型账本／授权、service/controller 描述符、token 启动 URL 或原始验收日志。
